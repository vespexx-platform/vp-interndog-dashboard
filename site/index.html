MCP로 대시보드 데이터 연결

이 대시보드의 매출·재고·VOC 데이터를 MCP 서버로 노출합니다. Claude(Desktop·Code)에 연결하면 채팅에서 바로 조회·분석할 수 있어요. 데이터는 대시보드 비밀번호로 로컬에서 복호화되며 서버 밖으로 나가지 않습니다.

1 · 설치

git clone https://github.com/vespexx-platform/vp-interndog-dashboard cd vp-interndog-dashboard pip install "mcp[cli]" cryptography

2 · Claude Code에 등록 (한 줄)

claude mcp add vp-interndog \ -e DASHBOARD_PASSWORD=대시보드_비밀번호 \ -- python3 "$(pwd)/mcp_server.py"

또는 · Claude Desktop 설정(JSON)

{ "mcpServers": { "vp-interndog": { "command": "python3", "args": ["/절대경로/vp-interndog-dashboard/mcp_server.py"], "env": { "DASHBOARD_PASSWORD": "대시보드_비밀번호" } } } }
